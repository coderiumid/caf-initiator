### Tindak lanjut 3 — GitLab untuk review command, peringatan `/caf-run` (tidak ada perubahan kode)

Dua pemeriksaan; keduanya berhenti dan dilaporkan, tidak ada kode yang diubah.

1. **`/caf-review` dan `/caf-fix-review` hanya bisa GitHub.** Premis "sudah mendukung GitHub dan GitLab" tidak sesuai kode:
   - Tidak ada satu pun `glab`, `GitLab` atau `MR` di `src/templates/review-command.js` dan `fix-review-command.js`.
   - Mekanisme posting adalah `gh` CLI dan REST GitHub: `gh pr list|view|diff`, `gh api repos/{owner}/{repo}/pulls/{n}/reviews` (satu PR Review dengan event `APPROVE`/`REQUEST_CHANGES`/`COMMENT`), `.../pulls/{n}/comments/{id}/replies`, `.../issues/{n}/comments`, `gh api user`. `allowed-tools` juga per pola `gh`.

Itu perubahan besar (template baru atau cabang per host, tool `glab`/REST GitLab, kontrak webhook) di luar "teks dan pemetaan yang jelas GitHub-only".
